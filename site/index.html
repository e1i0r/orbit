ORBIT

Stay in command of the code you did not write.

A terminal cockpit for coding agents. Each task in its own worktree, in phases that stop where you tell them to, and everything written down.

$ curl -fsSL https://getorbit.sh/install.sh | bash
GitHub Docs

Today

The agent writes more code than you can read, and you approve it anyway. Orbit keeps you the one who decides what ships.

In six months

Nobody on the team knows what is in the repo or why it was decided that way. Orbit keeps the full record of every run next to the code, not in a chat window somebody closed.

The loop

Four bands, twelve tabs, one window over every repository.

  1. In your CLI — Claude Code, Codex, OpenCode — you investigate, validate, and build the plan. From there it creates the tasks and hands them to Orbit over MCP.
  2. You open the cockpit and turn on autopilot.
  3. Orbit runs each task in its own worktree, phase by phase, stopping at the gates. The supervisor checks the result, fixes what is missing, and reports back.
  4. You read the diff and ship the PR.

Then you go back to your CLI, and it can read everything that happened while you were away.

How do I stay in command?

Gates you place, a supervisor you can redirect, and autopilot with an unread cap so the queue cannot outrun you.

What did it actually do?

An append-only record of every run: plan, prompts, reasoning, diff, cost, refusals. Agents report through MCP in structured events, not scraped stdout.

What does it cost me?

Nothing extra. Orbit runs the CLI you already have, under the plan you already pay for. No API key.

01

Getting started

Four commands, and the only one you have to think about is the third: point the cockpit at the directory your repositories are under.

  • orbit mcp install registers the server in Claude Code, Claude Desktop, Codex, OpenCode and Gemini.
  • orbit top ~/code is one window over every git repository under it. There is no list to register.
  • N writes a task, or ask your CLI in plain language and it writes them for you.

02

What you can do

Press m on anything. The menu lists every verb that applies to it — and the ones that do not, greyed, each with the sentence saying why.

  • A key that silently does nothing is indistinguishable from a key that is broken. So nothing is hidden: it is shown refused, with the reason.
  • Inside a task the same key carries both blocks — the twelve panes, and everything that can be done to the run.
  • Every verb in it is a command you can also run from a script, and the refusal is word for word the same.

03

A run, end to end

A task is not one long session. It is a list of phases, each small enough to check, with a verdict written down after every one.

  • A phase that gets it wrong is caught by the next one, or by you, before the one after it builds on the mistake.
  • A phase marked wait is a gate: the run stops in front of it. Between every pair of phases the answer is recorded — including "nobody was asked, autopilot was on".
  • Five flows ship built in. Yours are JSON, and the phase names are yours.

04

Autopilot

One key, and Orbit works the queue: it takes the next To Do, runs it through its flow without stopping at the flow's own gates, and lets the supervisor try to resolve what comes back needing attention.

  • It does not lift a pause you set by hand, and it does not lift a task marked critical.
  • unread-cap is the brake: once ten finished tasks are sitting unread, nothing new starts. The queue cannot outrun you.
  • Every gate it lifts is recorded as a decision nobody was asked about — a different fact about how much the result was checked.

05

Many tasks at once

Three runs going, in three worktrees, in one window.

  • Every task runs in a git worktree of its own, on its own branch. Two agents in their own checkouts is just two branches.
  • The Running band carries one row per live run: the phase, what it is doing right now, how long, what it has spent.
  • orbit join opens a second repository for a task that turns out to need one.

06

Reading what it did

The diff says what was written. The impact tab says whether it was right — what usually comes along with these files and did not this time.

  • Read from this repository's own history: invoice.py · 87% of the time (34/39) · not touched. Not a rule — the question a reviewer cannot ask a diff.
  • r runs the flow's own checks on the base and on the work at the same time. An exit code decided every line of it.
  • And what the agent says it did: what the change now asks of its callers, what it promises, and what it considered and did not do — which exists nowhere else.

07

The CLI, both ways

Orbit does not replace the CLI you already use. c hands it the terminal, in that task's worktree, with the task's context and Orbit's MCP server.

  • Quit it and you land back on the board. Orbit asks whether to write the session down as a task.
  • Twenty-two MCP tools, so the flow goes both ways: your CLI writes tasks, runs them, reads what happened, and steers them.
  • The agents Orbit runs report through the same protocol — structured events, not scraped stdout.

08

The supervisor

A second pair of eyes on the work, and a thread you steer it in. It goes out through the same CLI and the same subscription as your tasks.

  • orbit supervisor "the migration has to be reversible" — and it is still there next session, and next month.
  • With autopilot on, it is what tries to resolve a task that came back needing attention before you are asked to look at it.
  • What it concludes goes into what Orbit knows, so the conversation is not chat: what you say in it becomes something the runs carry.

09

What Orbit knows

Facts about your code, with a source and a reach, that arrive in the prompt before the agent works.

  • The model forgets between sessions and forgets when you swap it. CLAUDE.md and AGENTS.md are silos that empty the day the engine changes. This is kept outside all of them.
  • Six scopes, read closest-last: everything, a language, a repository, a directory, a file, one symbol.
  • A fact with no source does not get in — a sentence nobody can trace is indistinguishable from one the model made up.
